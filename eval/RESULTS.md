# Evaluation status

Quarry does not currently publish a representative retrieval benchmark. The
bundled `sample-goldset.json` contains three queries over `examples/sample-repo`
and is only a smoke test for the evaluation harness.

Use a representative repository and matching gold set that you are authorized
to process before reporting performance. See
[`docs/EVAL-AND-PRECISION.md`](../docs/EVAL-AND-PRECISION.md) for the method and
caveats.
